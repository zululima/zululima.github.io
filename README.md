# Blog of Akira Taguchi

The site at https://zululima.github.io: plain HTML and CSS, served by GitHub Pages straight from
`main`. `.nojekyll` keeps GitHub from running Jekyll, so `.well-known/` is served as it is.

- `index.html`, `about/`, `misc/`: the blog and its posts
- `portfolio/`: design and software work
- `mismeet/i.html`: the Mismeet invite page
- `.well-known/`: the Nostr address and the app link files
- `style.css`: the one stylesheet every page links

To get started, paste this into Claude Code:

```text
clone https://github.com/zululima/zululima.github.io into ~/Projects, serve it locally with python3 -m http.server and open it
```
